# Misión Campus Inteligente

## Proyecto
**Caso:** El misterio de los computadores desaparecidos.

### Problema
No existe un control suficientemente claro del préstamo y la devolución de los computadores del campus. Esto puede generar pérdidas, confusiones y dificultades para saber quién tiene cada equipo.

### Propuesta de solución: CampusTrack
Un sistema sencillo para registrar los equipos, las personas responsables, la fecha de préstamo y la devolución.

### Flujo de funcionamiento
1. Registrar el computador y su código.
2. Registrar los datos de la persona que lo solicita.
3. Verificar que el equipo esté disponible.
4. Guardar el préstamo y la fecha prevista de devolución.
5. Registrar la devolución y actualizar el estado del equipo.
6. Revisar los registros si falta un equipo o hay información incompleta.

### Pruebas propuestas
- **Caso 1:** todos los computadores están prestados. El sistema debe informar que no hay equipos disponibles.
- **Caso 2:** se devuelve un computador, pero la devolución no queda registrada. El sistema debe permitir detectar la inconsistencia y actualizar el registro.

### Relación con pensamiento computacional
- **Descomposición:** separar el inventario, los préstamos y las devoluciones.
- **Reconocimiento de patrones:** identificar préstamos vencidos o registros repetidos.
- **Abstracción:** conservar los datos importantes para controlar cada equipo.
- **Algoritmos:** definir los pasos para prestar, devolver y verificar equipos.
